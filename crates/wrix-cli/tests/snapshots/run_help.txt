Run an interactive sandbox.

Usage: wrix [--profile-config <file>] run [LAUNCH_OPTIONS] [DIR] [--] [AGENT_ARGS ...]

DIR defaults to CWD; without DIR, use -- before agent arguments.
Launcher options stop at DIR or --; after DIR, one optional -- is consumed.
Remaining arguments are passed unchanged to the agent, including --help.
Omitted Git options inherit repository policy, defaulting independently to false.
Tool caches: explicit launch choice > repository tool_caches.shared > shared default.
Private tool-cache mode does not disable caching or separate Nix/Celler policy.
Restricted Rust requires private tool caches; use --no-cache with WRIX_NETWORK=limit.
Installed stores: explicit mode > repository nix_store.mode > private default.
Shared mode requires a qualified runtime, explicit host approval and network=open.

Options:
  --profile-config <file>  Override generated project launch data with <file>.
  --dry-run                Inspect without preparing or executing a launch.
  --json                   Render the dry-run report as versioned JSON.
  --nix-store <mode>         Select private or shared installed Nix state.
  --cache                  Reuse shared worker tool caches for this launch.
  --no-cache               Use fresh private writable local tool caches for this launch.
  --git-deploy             Grant the deploy key for this launch; conflicts with --no-git-deploy.
  --no-git-deploy          Deny the deploy key for this launch; conflicts with --git-deploy.
  --git-sign               Grant the signing key for this launch; conflicts with --no-git-sign.
  --no-git-sign            Deny the signing key for this launch; conflicts with --git-sign.
  -h, --help               Print launcher help before DIR or --.

Enter sandbox.devShell for the consumer-pinned Wrix client and its generated immutable project configuration. WRIX_BIN and bare wrix select that same client. Outside consumer shells, use Home Manager, nix-darwin, nix profile add 'github:taheris/wrix#wrix', or temporary provision: nix shell 'github:taheris/wrix#wrix'. No fixed installation directory is required. Explicit --profile-config overrides the project default for run/spawn only. Host runtime and shared-controller compatibility are checked before effects; shared upgrades require explicit maintenance. Wrix does not silently select another CLI or rewrite container storage configuration.
